# Где я в распределении

Локальное веб-приложение: вводишь свои параметры и видишь для каждого признака перцентиль с интервалом и пометкой надёжности данных. Плюс:

- «**один из N**» в двух версиях: наивной (признаки независимы, доли перемножаются) и честной (гауссова копула с корреляциями из литературы, алгоритм GHK);
- **индекс конвенциональной привлекательности для женщин** — перцентиль среди мужчин группы, интервал и уверенность;
- **индекс положения в социальной иерархии** (SES);
- что подтянуть, чтобы сильнее всего сдвинуть итог;
- как результат меняется в зависимости от референс-группы: мир / Россия / Москва × пол × возраст × «студенты топ-вузов».

## Запуск

Сборка и зависимости не нужны. Достаточно открыть `index.html` в браузере.

Если браузер ограничивает `file://`, запусти локальный сервер:

```bash
cd where-am-i && python3 -m http.server 8000
```

и открой http://localhost:8000.

Проверки математики:

```bash
node where-am-i/test/run-tests.js
```

## Методология коротко

1. **Распределения.** Каждое задано для ячейки «регион × пол × 25–34». Другие возрасты, Москва и топ-вузы получаются сдвигом в латентных σ (в сторону «лучше») или прямым заданием. Группа «все / 18–64» — это смесь ячеек с демографическими весами.
2. **Перцентиль** = P(хуже) + ½·P(так же). Интервал (80%) строится Монте-Карло: погрешность ввода (с поправками на самооценку, онлайн-IQ, % жира «на глаз») плюс сдвиг распределения. Ширина сдвига зависит от надёжности данных: σ = 0.07 для хороших данных, 0.18 для экстраполяции, 0.33 для грубой оценки.
3. **Один из N.** N = 1 / P(не хуже по всем выбранным признакам). Наивная версия — произведение маргинальных долей. Честная — копула с корреляционной матрицей (приведённой к положительно определённой), которая считается в каждой ячейке пол×возраст отдельно, а затем смешивается. Так учитываются и корреляции, которые создают сами пол и возраст.
4. **Индексы.** Синтетическая популяция из 6000 человек с теми же маргиналами и корреляциями. Привлекательность — нелинейная функция: внешность доминирует; у роста порог и плато; тело = мало жира плюс сила с насыщением; ресурсы и статус через tanh; штрафы за курение и алкоголь. Пропуски заполняются условным ожиданием по известным полям. Веса разыгрываются (±30%), поэтому у результата есть интервал и уровень уверенности.

## Честно о слабых местах

- Сила, бизнес, публикации, аудитория, друзья и часть показателей образа жизни — **грубые оценки**: популяционных данных нет. У StrengthLevel и подобных баз сильный самоотбор, они годятся только как верхний якорь.
- По России нет популяционных DEXA и VO₂max. Использованы данные NHANES, FRIEND и HUNT со сдвигами, это помечено как экстраполяция.
- Веса индекса привлекательности — синтез нескольких исследований (Hitsch et al. 2010, Sell et al. 2017, Stulp et al. 2013, Asendorpf et al. 2011…), а не одна оценённая модель. Харизму, юмор, доброту и совместимость анкета не измеряет.
- Дальние хвосты (перцентили выше 99.5, N больше 10⁸) чувствительны к форме распределения и к корреляциям. Смотри на интервалы.
