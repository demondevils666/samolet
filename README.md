# Поворот к северному сиянию: P&L-дельта двух вселенных

Кейс: easyJet EZY1806, Рейкьявик → Манчестер, 27.02.2023, A320, круг 360° на FL370, чтобы оба борта увидели сияние.
Считаем Δ = B (рейс с кругом) − A (тот же рейс в тот же вечер без круга).

- `Aurora_turn_PnL_delta.pdf` — итоговый отчёт.
- `model.py` — модель. Факты на дату рейса (F) и оценки (E) считаются детерминированно, Монте-Карло — только для непредсказуемых параметров (U). Графики → `out/charts/`, числа → `out/results.json`.
- `build_report.py` — собирает HTML и печатает PDF через headless Chromium.

```bash
pip install matplotlib numpy
python3 model.py          # расчёт + графики
python3 build_report.py   # PDF
```
