# Монитор вакансий: спорт × аналитика / стратегия / коммерция / продукт

Python 3.10+, зависимости: `pip install requests beautifulsoup4 lxml openpyxl`

## Раз в неделю

```bash
cd sport_career/scripts
python monitor.py          # собирает вакансии и показывает только новые
python build_xlsx.py       # по желанию: пересобрать ../sport_career.xlsx
```

- Новые вакансии появятся в `out/new_<дата>.md` (таблица со ссылками) и `out/new_<дата>.csv`.
- Все актуальные лежат в `out/current.csv`. Флаг `--all` кладет в отчет все, а не только новые.
- id уже виденных вакансий хранятся в `state/seen.json`, первый раз увиденные отмечены датой. Удали файл, если нужно начать с нуля.
- Полный прогон занимает 10–15 минут: скрипт делает паузы между запросами и открывает карточки hh. Быстрый режим: `python monitor.py --no-details --max-pages 1` (без описаний фильтр по спорту хуже).
- Автозапуск по понедельникам в 10:00 через `crontab -e`:
  `0 10 * * 1 cd /путь/sport_career/scripts && python3 monitor.py >> out/cron.log 2>&1`

## Откуда данные

| Источник | Как берется |
|---|---|
| hh.ru | Публичная выдача `hh.ru/search/vacancy` (данные лежат JSON-ом в странице) по 13 запросам и ~40 работодателям: клубы РПЛ, КХЛ, ВТБ, лиги, РФС, Fonbet / Winline / Pari |
| api.hh.ru | Если задан `HH_TOKEN`, скрипт ходит в API вместо выдачи (см. ниже) |
| Яндекс | `yandex.ru/jobs/api/publications`: берет Плюс Фантех, Кинопоиск, Плюс и все со «спорт» в названии |
| Хабр Карьера, getmatch | Публичные списки по словам «спорт», «футбол», «ставки» и т.п. |

Запросы, работодатели и словари фильтра лежат в `config.py`. Беттинг помечается отдельно: по работодателю (Fonbet, Winline, Pari, BetBoom, Лига Ставок, Altenar…).
Оценка фита в скрипте эвристическая. В xlsx для текущих вакансий она проверена вручную, ручные оценки лежат в `data/fit_overrides.csv` (добавляй туда свои).

**Капчи и логины не обходятся.** Если hh покажет капчу или 403, скрипт остановит hh, допишет в отчет «hh.ru остановлен» и продолжит с остальными источниками.

## Токен api.hh.ru

С апреля 2026 `GET api.hh.ru/vacancies` без авторизации отвечает 403 (проверено 01.11.2026; также [Хабр, 11.08.2026](https://habr.com/ru/amp/publications/1069286/)). Справочники (`/areas`, `/dictionaries`) пока открыты.
Как получить токен: зарегистрировать приложение на [dev.hh.ru](https://dev.hh.ru), получить Client ID и Secret и выпустить токен приложения (`POST https://hh.ru/oauth/token`, `grant_type=client_credentials`). По данным Хабра, для этого теперь нужен подтвержденный аккаунт работодателя и модерация приложения, поэтому студенту проще жить без токена. Если токен появится:
```bash
export HH_TOKEN=...   # скрипт сам переключится на API
```

## Остальные скрипты

- `people_transfermarkt.py` выгружает персонал 16 клубов РПЛ с Transfermarkt (страницы Staff) в `data/people_tm.csv`. Страницы кэшируются на 7 дней; на антибот (HTTP 405) скрипт отвечает паузой, а не обходом.
- `tg_channels.py` проверяет Telegram-каналы по публичным превью `t.me/s/<канал>`: подписчики, дата последнего поста и «снежный ком» по ссылкам и репостам. `python tg_channels.py имя1 имя2` проверяет конкретные каналы. tgstat.ru из контейнера отвечал 403, его не трогаем.
- `build_xlsx.py` собирает `../sport_career.xlsx` из `out/` и ручных справочников `data/people.csv`, `data/events.csv`, `data/channels.csv`.

### Сверка с выпускниками: `match_alumni.py`

На вход подается список имен: CSV (колонка `name`/`ФИО`, остальные колонки переносятся в результат), TXT (имя в строке) или сохраненные HTML-страницы. Скрипт ищет совпадения в листах «Люди» обоих xlsx и в `data/*.csv` с учетом порядка «Имя Фамилия» / «Фамилия Имя», отчества, ё/е, латиницы (Shipulin ↔ Шипулин) и опечаток.
```bash
python match_alumni.py alumni.csv                       # → out/alumni_matches.csv
python match_alumni.py page1.html page2.html --min-score 90
```
`score` 100 означает точное совпадение фамилии и имени, 90+ похожую фамилию при том же имени, 80+ совпадение после транслитерации. Все, что ниже 100, проверяй глазами. Пример входа лежит в `data/v2/hse_insport_alumni.csv` (выпускники магистратуры ВШЭ по спортменеджменту).
