# Мужские бюджетные украшения (сталь/титан) на WB/Ozon: оценка ниши

Дата: 2026-11-13.

## Что запустить на ноутбуке (российский IP)

Нужен Python 3.9+. Скачай папку `jewelry_niche` и выполни в ней:

```bash
python3 collect_wb.py
```

Займёт ~5–10 минут. Получится `out/wb_cards.csv` (до 500 карточек на каждый из 6 запросов) и
`out/photos/` (по 3 фото у 60 самых «отзывных» карточек до 3 000 ₽). Пришли оба. Если упадёт —
пришли папку `out/raw`.

Ozon (по желанию, нужен браузер):

```bash
pip install playwright
```

```bash
playwright install chromium
```

```bash
python3 collect_ozon.py
```

Откроется окно браузера. Если Ozon покажет проверку, пройди её руками — скрипт подождёт.

## Себестоимость сета (цепь + браслет + кольцо + коробка), до склада WB

Цены 1688 — это цены «от», то есть за самый короткий или тонкий вариант.

| Сценарий | Закупка | Итого с байером, карго $5/кг, подготовкой, браком |
|---|---|---|
| Дешёвый (медианы) | 11,5 юаня ≈ 142 ₽ | **264 ₽** |
| Реалистичный (p75) | 25,5 юаня ≈ 316 ₽ | **454 ₽** |
| Качество+ | 40 юаней ≈ 496 ₽ | **651 ₽** |

Сам товар дешёвый: браслет 5 юаней ≈ 65 ₽, цепь 2–3,5 юаня. Но доставка, подготовка и брак добавляют
к любому сету ~110 ₽ сверху.

## Маржа на WB (FBO, комиссия 37,5 %)

Чистыми с проданного сета, диапазон соответствует выкупу 70–85 %:

| Цена | Себестоимость | ДРР 10 % | ДРР 20 % |
|---|---|---|---|
| 1 500 ₽ | 264 ₽ | 304–327 ₽ (20–22 %) | 154–177 ₽ (10–12 %) |
| 1 500 ₽ | 454 ₽ | 114–137 ₽ (8–9 %) | **убыток** |
| 2 500 ₽ | 264 ₽ | 744–767 ₽ (30–31 %) | 494–517 ₽ (20–21 %) |
| 2 500 ₽ | 454 ₽ | 554–577 ₽ (22–23 %) | 304–327 ₽ (12–13 %) |
| 2 500 ₽ | 651 ₽ | 357–380 ₽ (14–15 %) | 107–130 ₽ (4–5 %) |

Сет за 1 500 ₽ работает только на самой дешёвой фурнитуре: он не выдерживает ни нормального качества,
ни заметной рекламы. 2 500 ₽ — рабочая цена.

## «Образная» подача
Пока не проверено на выдаче. Косвенный сигнал: российские бренды с «образной» подачей стоят от 3 800 ₽
за один предмет (T-Ж, 13.11.2025). Наборов до 2 500 ₽ в такой подаче среди найденных брендов нет.
